# txt_reformat_gui — TXT 排版工具

TXT 小说/文章的批量排版整理工具。tkinter GUI，无第三方依赖。

## 用法

双击 `txt_reformat_gui.bat`，或：

```bash
python txt_reformat_gui.py
```

## 功能

支持「单个文件」或「目录（含子目录）」两种处理目标，三种排版模式：

| 模式 | 作用 |
|---|---|
| 拆分长单行 | 正文按句末标点逐句断行、压缩连续空行、章节重排 |
| 去除多空行 | 仅去掉连续空行，不合并断行、不改其他内容 |
| 全文重排 | 章节/序号前加空行，删除正文空格/tab/回车，仅保留句末标点换行 |

- `.bak` 备份文件自动跳过
- 处理前自动备份，可安全回退
